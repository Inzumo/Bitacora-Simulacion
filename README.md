# Bitacora-Simulacion

Reto de Diseño N°1

Primero pensé en una simulación con el polvo de estrellas de Carl Sagan que consiste en que todo es polvo de estrellas. La idea era que las partículas fueran a diferentes lados de la pantalla y estas crearan estrellas o planetas, y que cuando el usuario tocara la pantalla creara un punto de gravedad donde se reunirían las partículas; también que las estrellas estallaran en cierto tiempo o que la persona las estallara tocándolas y que todo se volviera otra vez polvo de estrellas. Pero hablando con el profe dijo que esto solo lo hace la inteligencia artificial fácilmente y que debería de diseñar más.
